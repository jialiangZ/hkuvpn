# Images

The pages use the **PNG** files in this folder. The **SVG** files of the
diagrams are their editable sources: edit the SVG, render it to the PNG
of the same name, and commit both.

The app icon is raster artwork, not a diagram. `hkuvpn-icon-source.png`
is the supplied original (1254px, white background); `hkuvpn-icon.png` is
the 256px transparent render used by the pages, and
`windows/mygo-app/assets/app-icon.png` is the same render used by the app.
`hkuvpn-icon.svg` is the previous icon's artwork, kept for reference only.

| File | Used by |
|---|---|
| `hkuvpn-icon-source.png` | Original app-icon artwork (1254px) |
| `hkuvpn-icon.png` | The README headers, the website, and the app icon |
| `hkuvpn-icon.svg` | Previous icon artwork (reference only) |
| `routing-flow-en.png` / `-zh.png` | The README and the website |
| `routing-flow-en.svg` / `-zh.svg` | Sources of the routing diagrams |
| `reverse-proxy-flow-en.png` / `-zh.png` | The README and the website |
| `reverse-proxy-flow-en.svg` / `-zh.svg` | Sources of the reverse-proxy diagrams |

The app's own icons live with the app, in `windows/mygo-app/assets/`.
