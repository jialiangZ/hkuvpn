# Images

The pages use the **PNG** files in this folder. The **SVG** files next to
them are the editable sources of the diagrams: edit the SVG, render it to
the PNG of the same name, and commit both.

| File | Used by |
|---|---|
| `hkuvpn-icon.png` | The README headers and the website |
| `hkuvpn-icon.svg` | Source of `hkuvpn-icon.png` |
| `routing-flow-en.png` / `-zh.png` | The README and the website |
| `routing-flow-en.svg` / `-zh.svg` | Sources of the routing diagrams |
| `reverse-proxy-flow-en.png` / `-zh.png` | The README and the website |
| `reverse-proxy-flow-en.svg` / `-zh.svg` | Sources of the reverse-proxy diagrams |

The app's own icons live with the app, in `windows/mygo-app/assets/`.
